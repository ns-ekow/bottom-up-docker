Curriculum

Fifteen weeks: weeks 1–12 are the core, weeks 13–15 extend it. Every module answers one question and follows the same seven steps: question → concept → experiment → build → read → trace → exercise.

This page is generated from curriculum.toml, the course’s single source of truth. tools/check-curriculum checks that every lesson matches it and that every reading path below exists at the pinned commit.

How bud grows

Each module's build adds one piece to bud, the container engine you write over the course.

  1. 01bud-init: a minimal PID 1 that forwards signals and reaps zombies
  2. 03bud run v0: re-exec into new namespaces and pivot_root into a rootfs
  3. 04bud gains user namespaces and capability dropping
  4. 05bud gains --memory, --cpus and --pids-limit
  5. 06bud gains a layered rootfs from local tarballs
  6. 07Project 1: minirunc runs OCI bundles; it becomes bud's runtime
  7. 08bud pull: resolve, authenticate, fetch, verify and unpack
  8. 09bud gains bridge networking and -p
  9. 10bud gains name-based DNS between containers
  10. 11bud becomes a daemon and CLI over a unix-socket HTTP API
  11. 12Project 2: bud build supports FROM, RUN, COPY, ENV and CMD with layer caching
  12. 13bud gains a default seccomp profile and capability set
  13. 14A volume plugin speaking Docker's plugin protocol
  14. 16Integrate and demo bud
